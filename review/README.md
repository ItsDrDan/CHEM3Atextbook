Everything needed to (1) get the revised book approved by the FCC Chemistry Department as the CHEM 3A OER, (2) collect structured faculty reviews, and (3) list the book in OER catalogs once it is approved and released.

| File | Who it is for | What it does |
|---|---|---|
| [01_DEPARTMENT_SUMMARY.md](01_DEPARTMENT_SUMMARY.md) | Chemistry Department (chair and CHEM 3A faculty) | Two-page case for approval: what the book is, COR coverage, what changed from the current OER, cost, licensing, accessibility, and what is still open. |
| [02_REVIEWER_FORM.md](02_REVIEWER_FORM.md) | Each faculty reviewer | A 10-criterion rubric (the same criteria the Open Textbook Library uses), a chapter sign-up table so reviewers can split the book, and a corrections table. |
