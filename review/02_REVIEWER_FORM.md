## Rubric

Rate each criterion 1–5 (5 = excellent, 3 = adequate, 1 = not usable) for the chapters you read, and add a sentence or two. Comments help more than numbers.

| # | Criterion | What to look for | Rating | Comments |
|---|---|---|---|---|
| 1 | Comprehensiveness | Covers the COR topics for these chapters at the depth CHEM 3A tests; the Chapter Guide, Key Terms, and Key Equations are complete. | | |
| 2 | Content accuracy | Chemistry, numbers, sig figs, and units are correct; answers to exercises and practice problems are right; values match the yellow and green sheets. | | |
| 3 | Relevance and longevity | Examples and applications (health care, biology, engineering, the Central Valley) fit our students and will not date quickly; updates would be easy. | | |
| 4 | Clarity | Prose is clear for students at this level; new terms are defined when first used; worked examples show every step. | | |
| 5 | Consistency | Terms, notation, and conventions (sig-fig rules, polarity cutoffs, STP, strong acids and bases) are the same throughout and match how we teach. | | |
| 6 | Modularity | Sections can be assigned on their own or in a different order without confusing students. | | |
| 7 | Organization and flow | Topics build in a logical order; prerequisites come before they are needed; cross-references point to the right sections. | | |
| 8 | Interface | Pages, figures, tables, Try It boxes, Explore It labs, and videos work and are easy to use, on a phone and in the PDF. | | |
| 9 | Grammar and mechanics | No spelling, grammar, or formatting errors that distract. | | |
