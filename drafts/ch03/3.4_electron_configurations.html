Learning Objectives

  • Write the full electron configuration of an atom using the filling order.
  • Use the s, p, d, and f blocks of the periodic table to write configurations directly.
  • Write noble-gas (shorthand) configurations.
  • Write the exception configurations of chromium and copper and explain why they happen.
  • Write configurations for main-group ions and recognize when an ion has a noble-gas configuration.

An orbital diagram shows every electron, but it takes room. An electron configuration gives the same information in one line: each occupied subshell followed by a superscript for the number of electrons in it. Nitrogen's orbital diagram from Section 3.3 becomes 1s2 2s2 2p3, read "one-s-two, two-s-two, two-p-three."

Why do we need this at all, when Section 3.2 already put electrons on Bohr rings? The rings tell you how many electrons are in each level, but not how they are arranged within it. Think of a kitchen: cups go on one shelf, plates on another, bowls in a cabinet, and everything has its set place. An electron configuration is the address of every electron: which shell (the shelf) and which subshell (the cabinet).

Writing Full Configurations

Fill subshells in the order from the diagonal method (1s 2s 2p 3s 3p 4s 3d 4p 5s ...) until you have placed all the electrons, filling each subshell to its capacity (s 2, p 6, d 10, f 14) before moving on. The superscripts must add up to the number of electrons.

Example \(\PageIndex{1}\): Full configurations

Problem. Write full electron configurations for (a) sodium, (b) chlorine, and (c) calcium.

Solution.

  • (a) Na, 11 electrons: 1s2 2s2 2p6 3s1
  • (b) Cl, 17 electrons: 1s2 2s2 2p6 3s2 3p5
  • (c) Ca, 20 electrons: 1s2 2s2 2p6 3s2 3p6 4s2 (4s fills before 3d)

Check. Superscripts: 2 + 2 + 6 + 1 = 11; 2 + 2 + 6 + 2 + 5 = 17; 2 + 2 + 6 + 2 + 6 + 2 = 20.

Reading Configurations from the Periodic Table

The periodic table is laid out by electron configuration. Its four blocks tell you which subshell is filling:

  • The s block (groups 1–2, plus He) is 2 columns wide, because an s subshell holds 2 electrons.
  • The p block (groups 13–18) is 6 columns wide.
  • The d block (groups 3–12) is 10 columns wide.
  • The f block (the two rows below the table) is 14 columns wide.

"Remember your shape": you do not need to memorize the capacities, because the block widths show them (2 columns for s, 6 for p, 10 for d, 14 for f). Then read the table like a book: start at hydrogen, read each row from left to right, then drop to the next row, and stop when you reach your element, writing each block as you pass through it. For s and p blocks, the shell number equals the row (period) number. For the d block, the shell number is the row number minus 1 (the row-4 d block is 3d); for the f block, it is the row minus 2 (the row-6 f block is 4f).

Example \(\PageIndex{2}\): Bromine from the table

Problem. Use the periodic table to write the full configuration of bromine (Br, Z = 35).

Solution. Read across the rows: row 1 gives 1s2; row 2 gives 2s2 2p6; row 3 gives 3s2 3p6. In row 4, cross the s block (4s2), the whole d block (3d10), and then go 5 columns into the p block to reach Br (4p5):

1s2 2s2 2p6 3s2 3p6 4s2 3d10 4p5

Check. 2 + 2 + 6 + 2 + 6 + 2 + 10 + 5 = 35. Bromine is in group 17, like chlorine, and both end in p5.

Example \(\PageIndex{3}\): Lithium, silicon, and vanadium, with the sum check

Problem. Read the periodic table to write the full configurations of (a) lithium, (b) silicon, and (c) vanadium.

Solution.

  • (a) Li, Z = 3. Row 1: H, He gives 1s2. Row 2: stop at Li, the first s column: 1s2 2s1.
  • (b) Si, Z = 14. Rows 1 and 2 in full (1s2 2s2 2p6), then row 3: Na, Mg (3s2), then Al, Si, two columns into the p block (3p2): 1s2 2s2 2p6 3s2 3p2.
  • (c) V, Z = 23. Rows 1–3 in full, then row 4: K, Ca (4s2), then three columns into the d block. The d block is "n minus 1," so in row 4 it is 3d, not 4d: 1s2 2s2 2p6 3s2 3p6 4s2 3d3.

Check. Add the superscripts: 2 + 1 = 3; 2 + 2 + 6 + 2 + 2 = 14; 2 + 2 + 6 + 2 + 6 + 2 + 3 = 23. Each matches Z.

Noble-Gas (Shorthand) Configurations

Configurations get long quickly. A noble-gas configuration replaces the inner electrons with the symbol of the noble gas from the row above, in square brackets. The part that is written out after the bracket shows the electrons beyond that noble gas.

  1. Find the noble gas at the end of the row above your element (He, Ne, Ar, Kr, Xe, or Rn).
  2. Write its symbol in brackets.
  3. Continue the configuration from the start of your element's row.

The electrons represented by the bracket are the core electrons. For main-group elements, the electrons in the highest-numbered shell are the valence electrons (Section 3.5).

Example \(\PageIndex{4}\): Shorthand configurations

Problem. Write noble-gas configurations for (a) phosphorus, (b) potassium, (c) bromine, and (d) the three elements of Example \(\PageIndex{3}\).

Solution.

  • (a) P is in row 3; the noble gas above is Ne. [Ne] 3s2 3p3
  • (b) K is in row 4; the noble gas above is Ar. [Ar] 4s1
  • (c) Br is in row 4: [Ar] 4s2 3d10 4p5
  • (d) Li and Si from Example \(\PageIndex{3}\): [He] 2s1 and [Ne] 3s2 3p2; V is [Ar] 4s2 3d3.

Check. Ne has 10 electrons, so P has 10 + 5 = 15 ✓. Ar has 18, so K has 18 + 1 = 19 ✓ and Br has 18 + 17 = 35 ✓.

Professor Tip

Elements in the same group end their configurations the same way: every group 1 element ends in s1, every group 2 element in s2, every halogen in s2 p5, and every noble gas after helium in s2 p6. If you know the group, you can check the end of your configuration in a second. Two transition metals, chromium and copper, break the filling order slightly; they are covered next.

Which form should you write? If a question asks for the "complete" or "full" configuration, write every subshell. Otherwise, the noble-gas form is quicker and leaves less room for mistakes, which saves time (and anxiety) on an exam. Configurations of f-block elements are rarely asked in this course.

Two Famous Exceptions: Chromium and Copper

Reading the table like a book works for almost every element you will meet, but two row-4 transition metals break the pattern, and they are a very common exam and homework question. Following the filling order, chromium (Cr, Z = 24) would be [Ar] 4s2 3d4, and copper (Cu, Z = 29) would be [Ar] 4s2 3d9. Their real ground-state configurations are:

Cr: [Ar] 4s1 3d5     Cu: [Ar] 4s1 3d10

In each, one 4s electron moves into the 3d subshell. The reason is stability: a half-filled d subshell (d5, one electron in each of the five d orbitals) and a completely filled d subshell (d10) are extra stable. The 4s and 3d subshells are very close in energy, so moving one electron costs little and buys that extra stability.

Picture chromium with the roommates of Hund's rule (Section 3.3). Written the "normal" way, two electrons have to share the 4s room while one 3d room sits empty:

4s [↑↓]   3d [↑][↑][↑][↑][  ]

One of the two roommates moves over into the empty room, and now all six electrons have rooms of their own: a half-filled 4s and a half-filled 3d.

Cr: [Ar]   4s [↑]   3d [↑][↑][↑][↑][↑]

Copper needs only one more electron to fill 3d, so one 4s electron moves over to complete it:

Cu: [Ar]   4s [↑]   3d [↑↓][↑↓][↑↓][↑↓][↑↓]

Same pattern below them: the elements just below chromium and copper in their columns, molybdenum (Mo) and silver (Ag), do the same thing: Mo is [Kr] 5s1 4d5 and Ag is [Kr] 5s1 4d10. Chromium and copper are the two to know.

Example \(\PageIndex{5}\): Chromium and copper

Problem. Write (a) the noble-gas configuration of chromium and (b) the full configuration of copper. Check each with the electron count.

Solution. Read the table as usual, then apply the exception: one 4s electron moves to 3d.

  • (a) Cr, Z = 24. The filling order gives [Ar] 4s2 3d4, which ends in s2 d4: move one 4s electron to make a half-filled 3d. [Ar] 4s1 3d5
  • (b) Cu, Z = 29. The filling order gives … 4s2 3d9, which ends in s2 d9: move one 4s electron to fill 3d. 1s2 2s2 2p6 3s2 3p6 4s1 3d10

Check. Cr: 18 + 1 + 5 = 24. Cu: 2 + 2 + 6 + 2 + 6 + 1 + 10 = 29. The exception moves an electron; it never adds or removes one, so the sum check still works.

Professor Tip

Make a flash card: never end a configuration in s2 d4 or s2 d9. If you catch yourself writing either one, you are in chromium's or copper's column, and one s electron moves over to the d subshell.

Configurations of Ions

An ion's configuration starts from the atom's configuration and then adds or removes electrons.

  • Anions: add electrons to the next open spot in the filling order. Cl (1s2 2s2 2p6 3s2 3p5) gains one electron to become Cl−: 1s2 2s2 2p6 3s2 3p6.
  • Cations: remove electrons from the highest-numbered shell first. Na (1s2 2s2 2p6 3s1) loses its 3s electron to become Na+: 1s2 2s2 2p6. Within the highest shell, take from the highest subshell first: aluminum (1s2 2s2 2p6 3s2 3p1) loses its 3p electron first and then its two 3s electrons, so Al3+ is 1s2 2s2 2p6.

Notice that Cl− now has the same configuration as argon, and Na+ has the same configuration as neon. Atoms or ions with the same electron configuration are called isoelectronic. Main-group elements tend to form the ions that are isoelectronic with a noble gas, which is the key to Section 3.5. This is why the predictable charges of Section 2.4 are predictable: lithium (1s2 2s1) loses one electron and Li+ (1s2) "looks like" helium; sulfur gains two and S2− looks like argon.

Example \(\PageIndex{6}\): Ion configurations

Problem. Write the noble-gas configuration of (a) Mg2+ and (b) S2−. Which noble gas is each isoelectronic with?

Solution. (a) Mg is [Ne] 3s2; removing both 3s electrons leaves [Ne], isoelectronic with neon. (b) S is [Ne] 3s2 3p4; adding two electrons gives [Ne] 3s2 3p6, which is the same as [Ar], isoelectronic with argon.

Check. Mg2+: 12 protons, 12 − 2 = 10 electrons, the same as Ne. S2−: 16 protons, 16 + 2 = 18 electrons, the same as Ar.

Biology Connection: Anatomy and Physiology

The ions your body depends on most are almost all isoelectronic with noble gases. Sodium (Na+) and magnesium (Mg2+) ions have neon's configuration; potassium (K+), calcium (Ca2+), and chloride (Cl−) ions have argon's. That stable, filled-shell arrangement is why each of these elements forms just one common ion, and why a lab report can list "sodium" or "calcium" without saying which charge: there is only one charge to report. Nerve impulses depend on moving Na+ and K+ across cell membranes, muscle contraction is triggered by Ca2+, and Mg2+ is needed by hundreds of enzymes, including those that use ATP.

Common Mistakes

  • Superscripts that do not add up. Always total them and compare with the electron count.
  • Writing 4d after 4p in row 4. The d block in row 4 is 3d (row number minus 1).
  • Using the noble gas in the same row. Use the noble gas from the row above: Na is [Ne] 3s1, not [Ar].
  • Writing s2 d4 or s2 d9 for chromium or copper. One 4s electron moves to 3d: Cr is [Ar] 4s1 3d5 (half-filled d) and Cu is [Ar] 4s1 3d10 (filled d).
  • Adding electrons for a cation. A positive ion has lost electrons; remove them from the highest shell, and within it from the highest subshell (2p before 2s).

Summary

  • An electron configuration lists occupied subshells with superscripts for the electrons in each; the superscripts add up to the electron count.
  • The s, p, d, and f blocks of the periodic table (2, 6, 10, and 14 columns wide) show which subshell is filling; reading across the rows gives the configuration.
  • Noble-gas configurations put the previous noble gas in brackets for the core electrons. Write the full configuration only when a question asks for "complete" or "full."
  • Read the table like a book; the d block is n − 1 (row 4 is 3d) and the f block is n − 2.
  • Exceptions: chromium is [Ar] 4s1 3d5 and copper is [Ar] 4s1 3d10, because half-filled and filled d subshells are extra stable; one 4s electron moves to 3d.
  • Anions add electrons; cations lose electrons from the highest shell. Main-group ions are usually isoelectronic with a noble gas.

Exercises

Exercise \(\PageIndex{1}\)

Write the full and noble-gas configurations of aluminum.

Hint

Al has 13 electrons. Fill subshells in diagonal-method order until the superscripts add to 13; for the shorthand, use the noble gas from the row above.

Answer

Al (13 electrons): 1s2 2s2 2p6 3s2 3p1, or [Ne] 3s2 3p1.

Exercise \(\PageIndex{2}\)

Which element has the configuration [Kr] 5s2?

Hint

Add krypton's electrons to the 2 shown to get Z for the neutral atom. Which element ends in s2 in row 5?

Answer

Strontium (Sr): 36 + 2 = 38 electrons, group 2, row 5.

Krypton has 36 electrons, so 36 + 2 = 38 = Z, which is strontium, the group 2 element in row 5.

Exercise \(\PageIndex{3}\)

Write the configuration of the oxide ion, O2−. Which noble gas is it isoelectronic with?

Hint

Write oxygen's configuration, then add 2 electrons to the last subshell. Which noble gas has that many electrons?

Answer

O is 1s2 2s2 2p4; adding 2 electrons gives 1s2 2s2 2p6, isoelectronic with neon.

Exercise \(\PageIndex{4}\)

Write the noble-gas configuration of the Be2+ ion and of a neutral germanium (Ge) atom. Check each by adding superscripts.

Hint

Be2+ lost 2 electrons from its highest shell. For Ge (Z = 32), start with [Ar] and read across row 4. The superscripts must add to the electron count.

Answer

Be is 1s2 2s2; losing its two 2s electrons leaves 1s2 (= [He]), 2 electrons = 4 − 2. Ge (Z = 32): [Ar] 4s2 3d10 4p2; 18 + 2 + 10 + 2 = 32.

Exercise \(\PageIndex{5}\)

A student writes copper's configuration as [Ar] 4s2 3d9. What is wrong, and what is the correct configuration? How many unpaired electrons does a copper atom have?

Hint

Copper is one of the exceptions. Which is more stable: a 3d subshell with 9 electrons or a completely filled one? Then draw 4s and 3d and count single arrows.

Answer

Copper is an exception: a filled 3d subshell is extra stable, so one 4s electron moves to 3d. Correct: [Ar] 4s1 3d10 (18 + 1 + 10 = 29). The five 3d orbitals are all paired, so there is 1 unpaired electron, the one in 4s.
