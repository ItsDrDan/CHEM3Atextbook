Learning Objectives

  • Describe shells, subshells, and orbitals, and give the number of electrons each can hold.
  • Describe the shapes of s and p orbitals.
  • Use the Aufbau principle, the Pauli exclusion principle, and Hund's rule.
  • Draw orbital diagrams for atoms and simple ions of the first 20 elements, and count unpaired electrons.
  • Spot a configuration that breaks the rules, and tell a ground-state configuration from an excited-state one.

The quantum-mechanical model keeps Bohr's idea of numbered energy levels but describes each electron by the region of space where it is most likely to be found. To keep track of many electrons at once, it helps to picture the atom as a hotel. The shells are the floors, the subshells are the types of rooms on each floor, and the orbitals are the rooms themselves. Each room holds at most two guests.

Shells, Subshells, and Orbitals

  • A shell (principal energy level) is numbered n = 1, 2, 3, ... Higher n means the electrons are farther from the nucleus on average and higher in energy.
  • Each shell contains one or more subshells, labeled s, p, d, and f. Shell n has n kinds of subshells: shell 1 has only 1s; shell 2 has 2s and 2p; shell 3 has 3s, 3p, and 3d; shell 4 has 4s, 4p, 4d, and 4f.
  • Each subshell contains a set number of orbitals, and each orbital holds at most 2 electrons.

Adding up the subshells gives the capacity of each shell: shell 1 holds 2 electrons, shell 2 holds 2 + 6 = 8, shell 3 holds 2 + 6 + 10 = 18, and shell 4 holds 2 + 6 + 10 + 14 = 32. (In general, shell n holds 2n2 electrons.)

Orbital shapes

An s orbital is a sphere centered on the nucleus; a 2s orbital is a larger sphere than a 1s. A p orbital has two lobes on opposite sides of the nucleus, like a dumbbell, and the three p orbitals in a subshell point along three perpendicular directions (x, y, and z). The d and f orbitals have more complicated shapes, which this course does not need.

Filling Orbitals: Three Rules

To find where an atom's electrons go in its ground state, place them one at a time using three rules.

  1. Aufbau principle ("building up" in German): electrons fill the lowest-energy orbitals first. The order of subshell energies is not simply 1, 2, 3; for example, 4s fills before 3d. The diagonal method in the figure gives the order.
  2. Pauli exclusion principle: an orbital holds at most two electrons, and if it holds two they must have opposite spins, drawn as one up arrow and one down arrow (↑↓). Picture spinning a basketball on your finger: it can spin clockwise or counterclockwise, and those two directions are "spin up" and "spin down." (Real electron spin is a quantum property, so the basketball is an oversimplification, but it is enough for drawing arrows.)
  3. Hund's rule: when filling orbitals of equal energy (such as the three 2p orbitals), put one electron in each orbital, all with the same spin, before pairing any of them. Think of roommates moving into a house: nobody crams into one bedroom while others sit empty. Everyone gets their own room first, and people double up only when the rooms run out. A p subshell is a three-bedroom house (6 electrons at most); a d subshell has five bedrooms.

To read the chart, write each shell as its own row (every subshell in a row has the same n), then follow each arrow from its tail to its head, starting at the top: 1s, then 2s, then 2p and 3s, then 3p and 4s, then 3d, 4p, and 5s, and so on.

Professor Tip: Learn to Build the Chart

Most instructors do not print the diagonal chart on exams. Practice building it from memory: rows 1s; 2s 2p; 3s 3p 3d; 4s 4p 4d 4f; and so on, then the diagonal arrows. Better still, learn to read the filling order straight off the periodic table (Section 3.4), which you do get on every exam.

Orbital Diagrams

An orbital diagram shows each orbital as a box (or line) and each electron as an arrow. The figure shows nitrogen and oxygen.

Example \(\PageIndex{1}\): Orbital diagram for carbon

Problem. Draw the orbital diagram for a carbon atom.

Solution. Carbon has Z = 6, so a neutral atom has 6 electrons. Fill in order: 1s gets 2, 2s gets 2, and the last 2 go into 2p. By Hund's rule they go into two different 2p orbitals with the same spin:

1s [↑↓]   2s [↑↓]   2p [↑] [↑] [  ]

Check. 2 + 2 + 2 = 6 electrons. Carbon has two unpaired electrons, which you will meet again when carbon forms four bonds in Chapter 6.

Example \(\PageIndex{2}\): Orbital diagram for sulfur

Problem. Draw the orbital diagram for sulfur and count its unpaired electrons.

Solution. S has Z = 16. Filling order: 1s (2), 2s (2), 2p (6), 3s (2), and the last 4 electrons go into 3p. Three 3p electrons go in one per orbital; the fourth pairs up in the first orbital:

1s [↑↓]   2s [↑↓]   2p [↑↓][↑↓][↑↓]   3s [↑↓]   3p [↑↓][↑][↑]

Sulfur has 2 unpaired electrons.

Check. 2 + 2 + 6 + 2 + 4 = 16. Oxygen, in the same group, has the same pattern in its outer subshell (2p4).

Lonely electrons and ions

An unpaired electron is alone in its orbital, a "lonely" electron in its own room. Chlorine's lonely 3p electron is a clue to how it reacts: chlorine tends to gain one electron to pair it. Compare chlorine and the chloride ion:

Cl (17 e−): … 3s [↑↓]   3p [↑↓][↑↓][↑]   (1 unpaired)

Cl− (18 e−): … 3s [↑↓]   3p [↑↓][↑↓][↑↓]   (0 unpaired)

Gaining one electron gives the lonely 3p electron a partner, fills the 3p subshell, and leaves chloride with the same arrangement as argon. To draw an ion, count its electrons first (Z − charge) and then fill in the usual order.

Professor Tip

Before drawing arrows, write the number of electrons and the filling order on scratch paper, and cross off subshells as you fill them. When you reach a p subshell, put in all the "up" arrows first, one per box, and only then go back and add "down" arrows. Finally, count the arrows: they must equal the number of electrons.

Ground State, Excited State, and Impossible Configurations

Everything above describes the ground state, the lowest-energy arrangement, which follows the Aufbau order (except for a couple of transition metals, chromium and copper, covered in Section 3.4). In Section 3.2 you saw that an atom can absorb energy and move an electron up to a higher level. Orbital diagrams show this too. Helium's ground state is 1s2. If one electron absorbs energy and jumps to the next level up, the atom is in its first excited state, written He* = 1s12s1 (the star marks an excited atom):

He (ground): 1s [↑↓]   2s [  ]     He* (excited): 1s [↑]   2s [↑]

The excited atom still has 2 electrons, so it is still helium; it simply holds more energy. The two unpaired electrons are usually drawn with the same spin. An excited-state configuration is possible (it just skips a lower spot), and the atom soon relaxes back to the ground state by giving off a photon.

An impossible configuration breaks a rule that can never be broken:

  • A subshell over capacity: 2s3 or 3p7 is impossible, because s holds at most 2 and p at most 6 (Pauli).
  • A subshell that does not exist: 1p or 2d is impossible, because shell n has only n kinds of subshells (1s only; 2s and 2p only).

Skipping a lower subshell, such as 1s22s12p1 for beryllium, is not impossible; it describes an excited state. Questions may ask which configuration is "impossible," which is "excited," or which is the "ground state," so read the wording carefully.

Example \(\PageIndex{3}\): Ground, excited, or impossible?

Problem. Classify each configuration as ground state, excited state, or impossible: (a) 1s22s22p63s1; (b) 1s22s22p53s1; (c) 1s22s32p4; (d) 1s21p2.

Solution. Answer each before looking at any answer choices, and check every subshell against the rules.

  1. 11 electrons filled in Aufbau order: the ground state of sodium.
  2. 10 electrons, but one has moved from 2p up to 3s while 2p still has room: an excited state of neon.
  3. 2s3 puts 3 electrons in an s subshell, which holds only 2: impossible.
  4. There is no 1p subshell; shell 1 has only 1s: impossible.

Check. Add the superscripts to find the element first (11 is Na; 10 is Ne), then compare with the Aufbau order.

Clinical Connection: Radiologic Technology

An X-ray tube works because atoms have shells. Inside the tube, electrons are accelerated by tens of thousands of volts and slam into a metal target, usually tungsten. Most of their energy becomes heat, but some collisions knock an electron out of a tungsten atom's innermost shell (n = 1, called the K shell in radiology). An electron from a higher shell immediately drops into the empty spot, and because the energy gap between these inner shells is very large, the photon it gives off is an X-ray. These characteristic X-rays have energies set by tungsten's shell structure, just as hydrogen's visible lines are set by its levels. The rest of the beam, a smooth spread of energies called bremsstrahlung ("braking radiation," from electrons slowing near nuclei), makes up most of a diagnostic X-ray beam.

Common Mistakes

  • Pairing p electrons too early. Hund's rule: one per orbital first, then pair.
  • Putting two arrows the same way in one box. Paired electrons must have opposite spins (Pauli).
  • Filling 3d before 4s. Use the diagonal method: 4s comes first.
  • Calling an excited state "impossible." Skipping a lower spot (He 1s12s1) is an excited state. Impossible means a broken rule: 2s3, 3p7, 1p, 2d.
  • Confusing orbitals with subshells. A p subshell is three orbitals and holds 6 electrons; one p orbital holds 2.

Summary

  • Shells (n = 1, 2, 3, ...) contain subshells (s, p, d, f), which contain orbitals (1, 3, 5, 7). Each orbital holds up to 2 electrons, so s, p, d, and f subshells hold 2, 6, 10, and 14.
  • Aufbau: fill lowest energy first (1s 2s 2p 3s 3p 4s 3d 4p ...). Pauli: at most 2 electrons per orbital, opposite spins. Hund: spread out in equal-energy orbitals before pairing.
  • Orbital diagrams show each orbital as a box and each electron as an arrow. Count the arrows: they must equal the electrons (Z for an atom, Z − charge for an ion).
  • Ground state follows Aufbau; an excited state has an electron moved up (He* = 1s12s1); an impossible configuration overfills a subshell or uses one that does not exist.

Exercises

Exercise \(\PageIndex{1}\)

How many electrons can the third shell (n = 3) hold, and how are they divided among its subshells?

Hint

Shell 3 has three kinds of subshells. How many orbitals does each have, and how many electrons fit in one orbital?

Answer

18: 3s holds 2, 3p holds 6, and 3d holds 10.

Each orbital holds 2 electrons, and 3s, 3p, and 3d have 1, 3, and 5 orbitals, so 2 + 6 + 10 = 18.

Exercise \(\PageIndex{2}\)

Draw the orbital diagram for fluorine. How many unpaired electrons does it have?

Hint

Fluorine has 9 electrons. Fill 1s, then 2s, then 2p; in 2p, put one electron in each box before pairing (Hund's rule), then count single arrows.

Answer

F has 9 electrons: 1s [↑↓] 2s [↑↓] 2p [↑↓][↑↓][↑]. One unpaired electron.

Exercise \(\PageIndex{3}\)

A student draws phosphorus's 3p subshell as [↑↓][↑][  ]. Which rule is broken, and what is the correct drawing?

Hint

Phosphorus has three 3p electrons and three 3p orbitals. Which rule says to put one electron in each orbital, same spin, before pairing?

Answer

Hund's rule. The three 3p electrons should go one per orbital with the same spin: [↑][↑][↑].

Exercise \(\PageIndex{4}\)

Which configuration is impossible: (A) 1s22s22p63s23p3; (B) 1s22s22p63s23p7; (C) 1s22s12p3; (D) 1s22s22p2?

Hint

Check each subshell against its capacity (s 2, p 6, d 10). An excited state is possible; an overfilled subshell is not.

Answer

B: a p subshell holds at most 6 electrons, so 3p7 cannot exist. A is phosphorus and D is carbon (both ground state). C is carbon in an excited state (one 2s electron moved up to 2p), which is possible.

Exercise \(\PageIndex{5}\)

Draw the orbital diagrams of the outer subshells for an oxygen atom and for the O2− ion. How many unpaired electrons does each have?

Hint

Count electrons: O has 8, and O2− has gained 2. Fill 2p one per box before pairing, then count boxes with a single arrow.

Answer

O (8 e−): 2s [↑↓] 2p [↑↓][↑][↑], 2 unpaired. O2− (10 e−): 2s [↑↓] 2p [↑↓][↑↓][↑↓], 0 unpaired (the same as neon).
