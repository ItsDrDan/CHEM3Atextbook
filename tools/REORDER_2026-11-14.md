# Draft book reorder to COR order (2026-11-14)

Done with Dr. Dan's go-ahead ("Yes, reorder"), on the draft book only (Workbench, project DTvJm7TcCY). The live book was not touched.
Method: MindTouch API from a signed-in browser tab. `POST /@api/deki/pages/{id}/move?to=<path>&title=<title>` (moves the page and its subpages; content and transclusions unchanged) and `PUT /@api/deki/pages/{id}/order?afterid=<id>` (display order). 199 moves, 0 failures.

**To undo a move:** move the page id back to its old path and title (table below; chapter-level rows move whole subtrees). The original tree, with every id, title and path, is in the session log and can be rebuilt from this table plus `tools/live_tree.txt` (same titles, live-book ids).
